## 详细步骤说明

### 第一步：生成 IPK 包 (本地电脑)

```bash
# 1.1 克隆仓库
git clone https://github.com/sunqian1117/luci-app-srun.git
cd luci-app-srun

# 1.2 运行构建脚本
./build.sh

# 1.3 查看生成的包
ls bin/
# 输出: luci-app-srun_1.0.0-1_all.ipk
```

**预期结果：**
```
✓ Package built successfully!
Package: /path/to/bin/luci-app-srun_1.0.0-1_all.ipk
```

---

### 第二步：传输到路由器

#### 方案 A：使用 SCP

```bash
scp bin/luci-app-srun_1.0.0-1_all.ipk root@192.168.1.1:/tmp/
```

**流程图：**
```
[本地电脑] --SCP--> [路由器 /tmp/ 目录]
   IPK 文件            临时存储
```

#### 方案 B：使用 Web 界面

```
浏览器 → http://192.168.1.1
       → System → Software
       → Upload Package
       → 选择 IPK 文件
       → Install
```

**流程图：**
```
[本地电脑] --HTTP--> [路由器 LuCI]
   选择文件            自动安装
```

---

### 第三步：安装软件包 (路由器上)

```bash
# 3.1 连接到路由器
ssh root@192.168.1.1

# 3.2 安装依赖 (如果还没安装)
opkg update
opkg install curl jsonfilter coreutils-base64 openssl-util

# 3.3 安装 IPK 包
opkg install /tmp/luci-app-srun_1.0.0-1_all.ipk
```

**安装过程：**
```
opkg install
    │
    ├─> 检查依赖
    ├─> 解压 IPK
    ├─> 复制文件到系统
    ├─> 运行 postinst 脚本
    └─> 完成 ✓
```

---

### 第四步：配置和启动

```bash
# 4.1 编辑配置
vi /etc/config/srun

# 4.2 启用服务
/etc/init.d/srun enable

# 4.3 启动服务
/etc/init.d/srun start

# 4.4 检查状态
/etc/init.d/srun status
```

**服务生命周期：**
```
Disabled → Enable → Start → Running
   │          │        │        │
   └──────────┴────────┴────────┘
   配置    开机启动   手动启动   运行中
```

## 文件安装位置

安装后文件分布：

```
OpenWrt 路由器文件系统
│
├─ /etc/
│   ├─ config/
│   │   └─ srun                    # 配置文件
│   └─ init.d/
│       └─ srun                    # 服务脚本
│
├─ /usr/
│   ├─ bin/
│   │   └─ srun-auth              # 认证命令
│   └─ lib/
│       ├─ lua/luci/              # LuCI 界面文件
│       └─ srun/                  # 库文件
│
└─ /tmp/
    └─ luci-app-srun_*.ipk       # 安装包 (安装后可删除)
```

## 时间估算

| 步骤 | 预计时间 | 说明 |
|------|----------|------|
| 克隆仓库 | 1-2 分钟 | 取决于网络速度 |
| 构建 IPK | < 10 秒 | 脚本执行很快 |
| 传输文件 | < 1 分钟 | 取决于网络速度 |
| 安装软件 | 1-2 分钟 | 包括依赖安装 |
| 配置服务 | 2-5 分钟 | 手动编辑配置 |
| 测试验证 | 1-2 分钟 | 测试认证功能 |
| **总计** | **5-15 分钟** | 首次安装 |

更新安装时间更短（2-5 分钟）。
